**Слово юзера 2026-07-26 (блок 3.5, после партий A/B):** «отсматривать на проде
не стану, мне нужно представить всё, что ты изменил, в чате в удобном формате —
там и будем обсуждать»; плюс «нужно, чтобы где-то сохранялся fallback языка,
который был до этих партий».

**Why:** копирайт, в отличие от вёрстки и глифов, полностью проверяем по тексту —
гонять юзера по экранам ради строк дорого и бессмысленно. А массовая замена слов
без снимка прежнего состояния необратима на глаз.

**How to apply:**
- Закончив партию копирайта, **выдать в ответе таблицу «было → стало»**,
  сгруппированную по смыслу (термины · экран · тип строки), а не список коммитов.
  Прод-ревью для копирайта НЕ запрашивать (для вёрстки/иконок правило прежнее —
  закрывает прод-ревью юзера).
- Перед свипом текста: **тег отката** + машинный слепок строк. Сделано для
  блока 3.5 — тег `v2.5-pre-gothic-copy` (`c5bd668`),
  `audit-v2/COPY-INVENTORY-PRE-3.5.txt` (810 строк «до»),
  `audit-v2/COPY-FALLBACK-PRE-3.5.md` (построчное было→стало по партиям).
  Каждую следующую партию дописывать в этот же fallback-док.
