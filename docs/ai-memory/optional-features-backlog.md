## Задачи (основное приложение)
- **Idea 5 — вид «Календарь»** (отложен 2026-06-19: **ценность средняя, стоимость
  высокая**). Новая 4-я страница: месячная сетка 7×N, в ячейках дней задачи с
  дедлайном. Навигация по месяцам (готик меч-шеврон `dl-month-chevron`), чипы задач
  (цвет/приоритет/статус дедлайна), «+N ещё», клик по дню → задачи/создать с датой,
  маркировка сегодня/просрочено. Данные есть (`deadline`), новой модели НЕ надо;
  учесть повторы (`cycleChecked`/`nextReset`). Готик-вёрстка с нуля + адаптив +
  switchPage на 4 страницы.
- **Idea 2 — счётчик серий (streak)** для повторов. Отложен (сомнения в готик-аскет-
  фите). Мёртвая CSS-заглушка уже вычищена (G4-5). Не возвращать без запроса.
- **S1-9** `.task-item{overflow:hidden}` — архитектурная заметка (потолок для inline-
  дропдаунов/тултипов на строке). Не баг.
- **G4-3** — `render()` пересоздаёт все Sortable; смягчено `renderListOnly`+ленивые
  sub; настоящий фикс упирается в 7c/Svelte. Перф-замечание.

  (а) ввод — строка-чипы под заголовком vs инлайн `*тег` в теле; (б) фильтр — облако
  тегов под поиском vs через строку поиска. Реюз идей тег-системы ЗАДАЧ
