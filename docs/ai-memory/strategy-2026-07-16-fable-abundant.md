ещё ~6-7 потом; Opus почти безлимитен. **Стратегия 2026-07-12 (подготовка
Opus) ЗАМЕНЕНА: Fable исполняет качество-критичное САМ.** Operating doc =

протокол автономного лимита, definition of done).

ревью юзера ВЕЧЕРНЕЙ ПАЧКОЙ, вопросы вкуса → audit-v2/REVIEW-QUEUE.md, не

DUSK не нравятся + полоски приоритета → эмбер; кап ~2.5-3 лимита; xhigh).
Ф3 = B4-01 large-screen + B4-02 поповеры. Ф4 = Android TWA (важно-не-срочно).
Ф5 = Opus-хвост (B7-B14, W2-механика, W3, синк-стресс). Аудит B7-B13 больше
не «отложен» — просто в конце и на Opus. B1-10 виртуализация/px→rem/Tauri=O2.

СПРОСИТЬ юзера переключить /effort; не начинать существенно-несоответствующую.**

слайса/партии; /compact только при обрыве незакоммиченного.
