## Залоченные решения (отменяют часть старого плана)
- **3-way мерж** против хранимого `baseline` (последний синканутый снимок). Base-дифф =
  ДЕТЕКТОР конфликта (не зависит от часов); часы = только тайбрейк при споре за одно и то же.
- **Глубина слияния:** задачи И группы И шаблоны — **по полям** (независимые правки разных
  полей складываются; спор за одно поле → новее); подзадачи — **набор по uid** (две новые
  подзадачи обе выживают; спор за одну → новее → **подзадачам добавляем свой `updatedAt`**);
  заметки — **целиком, «оставить ОБЕ копии»** при конфликте (слияние HTML-текста по абзацам
  отвергнуто как большое+рискованное; нужен движок дерева или переархитектура заметок в блоки).
- **Конфликты — БЕЗ всплывающих окон** (ОТМЕНЯЕТ прежнее «спрашивать»; обновлён CLAUDE.md).
  Авто-дефолт в живое состояние, проигравшее → **карантин-журнал**. Дефолты: одно поле →
  новее; **удал-против-правки → по умолчанию УДАЛИТЬ** (правленая копия в карантин,
  восстановима); заметка → новее живёт, вторая в карантин.
- **Карантин = синкается** (решающий аргумент: иначе проигравшая правка восстановима только
  на устройстве, что синкалось вторым; синк доносит её до всех, вкл. то, чья правка проиграла).
  Реализация: **append-only, неизменяемые записи, объединение по uid** (так нет рекурсии);
  флаг «решено»/`resolvedAt` по «кто новее»; «восстановить» = обычная правка данных. Висит
  **до выбора пользователя**; ненавязчивый **счётчик нерешённого** (бейдж), без модалок.
- **Часы — монотонное число сейчас:** `updatedAt = max(Date.now(), _lastTs+1)`. Тип остаётся
  числом. Полный HLC отложен (drop-in потом). Часы устройства (не сеть) т.к. офлайн-first.
- **Модель — 3 правки сейчас (безопасны):** (1) `updatedAt` подзадачам; (2) штамп `updatedAt`
  при архив/restore (и notes↔notesArchive) — смену локации контент-дифф не ловит; (3) монотонные часы.
- **groupId девайс-локальный** → в мерже транслировать через `_groupUid` (int→uid в каждом
  входе, мерж, потом обратно по итоговой таблице групп). int-id реиндекс после мержа (паттерн gidMap).
- **НЕ синкаем:** sortMode/sortModeOverrides, next* аллокаторы, UI-префы в отдельных LS-ключах
  (ручной порядок задач едет в task.order, который синкается).
- **Отложено ОБЯЗАТЕЛЬНО (не «по желанию»):** чистка надгробий И чистка карантин-журнала (оба
  растут безгранично) → Фаза 4.
