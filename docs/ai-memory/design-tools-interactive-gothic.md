Пользователь явно похвалил дизайн X-6 авто-повтор тумблера и сказал: «если б ты
всегда делал такой крутой дизайн как с тумблером, в дальнейшем используй те же
инструменты при построении дизайна».

**Why:** задал планку качества дизайна для всего DUSK впредь.

**How to apply:** при дизайн-задачах использовать те же инструменты/подход, что
дали этот результат:
- скилл **frontend-design** (bold direction, distinctive typography, motion,
  atmosphere) — применять и для готик-контекста DUSK;
- **настоящие интерактивные контролы** (CSS-driven свитчи: трек+knob, состояния
  через класс/`:checked`, `--ease-spring`/`--ease-gothic` переходы), а не
  текст-пилюли «вкл/выкл»;
- **ornate-готик глифы** (детализир. SVG: лунный круг с фазами, оуроборос,
  крылатые часы) — см. [[icons-must-be-ornate-gothic]];
- сперва ёмкое HTML-превью с вариантами иконки/контрола/раскладки (отдаю файлом,
  сам не скриншочу — [[no-screenshot-html-previews]]), пользователь выбирает,
  потом вживляю и верифицирую харнессом;
- упор на КАЧЕСТВО, не количество вариантов.

Конкретный референс-образец: лунный тумблер авто-повтора в дедлайн-модалке
(`.dl-repeat-toggle` / `.dl-rt-switch` лунная фаза серп→полнолуние).
