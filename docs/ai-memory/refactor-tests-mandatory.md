На рефактор-кластере DUSK (U-1 modal-controller, U-2 фабрика дропдаунов, U-3 единый
collapse, P-E дедлайн подпунктов — и любой будущий рефактор) пользователь ТРЕБУЕТ:
билдить **тщательные тесты, проверяющие что НЕ произошло деградаций**.

**Why:** рефактор-кластер = высокий blast radius (трогает все модалки/пикеры/анимации).
Пользователь сам ревьюит визуал, но регрессии в поведении (фокус, Esc, открытие/закрытие,
DnD, undo) глазом не поймать → нужна автоматическая проверка ДО коммита.

**How to apply:**
- Перед рефактором каждого блока — снять baseline-поведение (что и как работает СЕЙЧАС),
  потом доказать тестами что после рефактора оно идентично.
- Playwright-харнесс в `D:\tmp\pw` (system Chrome, см. [[dusk-headless-screenshot]] и
  TESTING HARNESS в [[grimoire-notes-plan]]). Реальный `.click()` для execCommand-путей.
- Покрывать ВСЕ затронутые сущности (напр. U-1 = каждая модалка: открытие/Esc/backdrop/
  фокус-трап/возврат фокуса/exit-аним), не только happy-path.
- `node --check app.js` чистый + тесты зелёные ПЕРЕД коммитом. Временные превью/тест-файлы
  из корня репо удалять перед коммитом.
- Связано: [[refactor-direction-2026-06]] (если есть), [[audit-2026-06-fix-progress]].
