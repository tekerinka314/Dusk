## Ключевые технические уроки (НЕ забыть)
1. **CSS grid НЕ анимирует ширину при смене типа трека.** `grid-template-columns` `px↔fr` и `px↔minmax`
   НЕ интерполируются → схлопывание мгновенное (замер: detail 486→0 за кадр). Решение: **flexbox** —
   анимируемый `flex-basis` (px↔% интерполируется), filler `flex:1 1 0` плавно ужимается. Перевёл всю
   `.grim-layout` (focus/full/collapse) на flex.
2. **blur-rerender съедает клик.** Клик по листу → blur тела → `grimCommit`→`renderGrimList` пересобирал
   лист между mousedown/mouseup → узел пропадал → клик НЕ срабатывал (открытие/тоггл = 2 клика). Фикс:
   `grimCommit(e)` по `e.relatedTarget` — blur на любой лист = обновление НА МЕСТЕ (`_grimSyncActiveLeaf`,
   узел жив); уход в не-лист = полный рендер. Всплытие заметки наверх: при switch делает grimOpen.
3. **Анимацию статикой не проверить** — мерить ширину во времени: `_anim.js` сэмплит
   `getBoundingClientRect().width` каждые 40ms; видно snap vs градиент.
4. **HTML-превью иконок:** `_glyphs2.html` + `_g2shot.js` (element-screenshot `.cand`.nth(i) для
   кандидата ниже фолда; fullPage/clip ловит «outside image»). Юзер выбирает из превью ПЕРЕД внедрением.
