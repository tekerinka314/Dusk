Юзер-мандат 2026-07-17 (везде и всегда, не только DUSK):

1. Перед началом любой существенной задачи — проанализировать **вообще все**
   установленные скиллы (полный список в контексте сессии), не по памяти и
   не по шортлисту.
2. Загрузить **все** скиллы, которые реально могут пригодиться и быть ценны
   для этой конкретной задачи — НЕ только один «лучший матч». Критерий:
   «изменит/улучшит ли содержимое скилла работу», а не «топикальное совпадение».
3. `find-skills` — **обязателен для КАЖДОЙ задачи**, не только при явном
   пробеле: искать скиллы под аспекты, которые установленные не покрывают
   идеально. Найденные ценные — установить и пропустить через этот же цикл
   (скан → загрузить все применимые) до начала работы. Единственное
   исключение: в ЭТОЙ сессии уже был find-skills по тому же классу задач
   (поиск повторился бы дословно) — тогда явно сказать об этом в п.4.
4. Сказать: какие скиллы загружены и почему; что find-skills выполнен (или
   исключение); какие пограничные скиллы пропущены — по строке причины на
   каждый.

Пп.1-3 не рекомендация: работа, начатая с меньшим набором скиллов, чем
проходит планку п.2, или без find-skills — начата НЕПРАВИЛЬНО; остановиться
и прогнать цикл.

**Why:** юзер ДВАЖДЫ за 2026-07-17 указал, что я недоиспользую скиллы — беру
один-два очевидных вместо полного набора ценных, и не ищу отсутствующие
через find-skills.

**How to apply:** цикл вжит в CLAUDE.md §«Skill usage» (отредактирован
2026-07-17); в других проектах применять из этой памяти. Пропускать только
для чисто разговорных реплик без кода/дизайна/ресёрча. См. также
[[skills-toolkit-2026-07]].
