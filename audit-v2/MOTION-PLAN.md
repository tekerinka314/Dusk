# MOTION-PLAN — перестройка мотион-системы DUSK (2026-07-17)

**Цель:** анимации перестают ощущаться лаганными — в первую очередь на телефоне,
но и на ПК. «Лаг» = (а) дропнутые кадры из-за пейнта/лейаута каждый кадр,
(б) вязкость: слишком длинные дюрации и `transition: all` на частых действиях.

**Скиллы, применённые к плану:** impeccable (optimize), emil-design-eng
(framework решений: что анимировать, дюрации, изинги), microinteractions
(фидбек ≤100мс, масштаб фидбека к событию), systematic-debugging (аудит до
фиксов), writing-plans. web-perf — фаза верификации (замер в браузере).

## Правила новой системы (binding)

1. **Вечные (infinite) анимации — только transform/opacity.** Свечение =
   статичная тень на элементе/псевдослое + пульс opacity (паттерн PERF-2).
2. **Каждый transition называет свойства.** `transition: all` запрещён.
3. **Частые действия быстрые, ритуалы медленные.** Пресс ≤160ms; дропдауны
   ~180ms; шиты/модалки ≤300ms; ритуалы (печать, собор) остаются 520ms+.
   Выход всегда быстрее входа.
4. **Тач ещё быстрее:** на `(pointer: coarse)` токены короче (см. W4).
5. **backdrop-filter — только малые области и малые радиусы на мобиле.**
   Большая карта приложения на мобиле — непрозрачный фон без блюра.

## Волны

### W1 — вечные пульсы → opacity-only (podозреваемый №2)
- `emblemPulse`: статичный drop-shadow средней силы, пульс только opacity.
- `pulseLive`/`pulseCritical` (бейджи): тень переезжает на `::after`
  (inset:0, border-radius наследуется, макс. интенсивность), пульс opacity.
- `pulseSide` (ряд): аналогично через существующий псевдослой ряда или
  `::after`; если конфликт псевдослоёв — оставить, но проверить площадь.
- `dangerPulse`, `armedPulse`, `portalPulse`: тот же паттерн; маленькие точки
  (sync-dot) можно оставить как есть (площадь мизерная) — решать по месту.
- Одноразовые вспышки (`sealFlash`, `milestoneGlow`, `cathedralFlash`,
  `checkPulse*`) — НЕ трогаем: редкие, короткие, это ритуалы бренда.

### W2 — backdrop-filter диета (подозреваемый №1)
- `.todo-app`: на `max-width: 640px` → `backdrop-filter: none` + фон плотнее
  (var(--bg-app) с поднятой альфой), визуально фон за картой почти чёрный —
  разницы почти нет, GPU освобождается целиком.
- Шиты/поповеры blur ≥10px → 6–8px на мобиле; скримы 3–4px оставить.
- Десктоп не трогаем (GPU тянет, стекло — часть стиля).

### W3 — sweep `transition: all` → явные списки (58 мест)
Замена на минимальный реальный набор места: обычно
`color, background-color, border-color, box-shadow, opacity, transform`.
Деградация при промахе = анимация становится мгновенной (не ломается layout) —
приемлемо, ловится визуальным ревью.

### W4 — ретюн темпа
- Глобально: `--dur-standard` 340→300ms.
- `@media (pointer: coarse)`: `--dur-quick` 220→170ms, `--dur-standard`
  →260ms, `--dur-collapse` 280→230ms. `--dur-ritual` не трогаем нигде.
- Проверить пресс-фидбек F2 (:active) ≤160ms.

### W5 — гигиена
- `taskArchive`/`taskDelete`: длительность ≤280ms (reflow-окно короче).
- Точечные layout-transition (width/height/margin) — глянуть 7 width-мест,
  переводить только где тривиально (слайды пилюль по ширине — осознанный
  дизайн, оставить).

### W6 — верификация
- `npm test`, `npm run build` зелёные.
- Headless-скрин главной — статика не поехала (тени на месте в покое).
- On-device: юзер на телефоне; при сомнениях — web-perf скилл (DevTools
  trace, CPU 4x эмуляция) отдельной сессией.
