# F2-MOBILE — целостный редизайн мобильного слоя (утверждён юзером 2026-07-17)

Исполнитель: **Fable 5, effort XHIGH** (запросить `/effort xhigh` при старте, если
не дефолт). Одна автономная сессия. Контекст: Ф1 (слайсы 1-6) + само-аудит
(билды -7/-8) задеплоены, но качество юзером НЕ принято — латание метрик вместо
целостного дизайна. Этот план — ответ: редизайн одним проходом.

## Решения юзера (binding)

1. **Автономия — гибрид:** всё вживляю сам БЕЗ блокировки; 1-2 действительно
   радикальных хода дополнительно показываю HTML-превью-файлом (варианты), но
   вживляю рекомендованный вариант сразу — превью остаётся для смены решения
   при ревью. Ревью юзера постфактум (тег отката страхует).
2. **Скоуп — ВЕСЬ мобильный слой:** главная (глубоко: карточка, подзадачи,
   тулбар, шапка, группа, шит) + архив + гримуар (список и редактор) + модалки
   + синк-панель + пустые состояния. Единый визуальный язык везде.
3. **Тулбар:** блок ДАННЫЕ убрать из постоянного «шкафа», НО функционал
   обязан остаться полностью доступным (⋯-шит тулбара / иное место — решить
   дизайном). НИЧЕГО не удалять, только перенос. Деструктив (удалить всё)
   уходит с глаз — плюс.
4. **Workflow (adversarial-проверка) — дёшево:** агенты **sonnet-5 effort
   medium** (финальный судья opus-4.8 high), всего ~5-7 агентов, 1-2 раунда.
   НИКАКИХ fable-агентов. Линзы: «владелец за 10 сек», плотность/иерархия,
   touch-эргономика, готика-идентичность, motion. Запуск воркфлоу юзером
   одобрен в рамках этого плана.

  в одно слово ~150px; дыры в вертикальном ритме.

  Закрепить-центр / Сохранить-шаблон-право.
