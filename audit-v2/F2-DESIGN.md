# F2-MOBILE — дизайн-система мобильного слоя (2026-07-17)

Норт-стар редизайна. Критерий для само-проверки и adversarial-ревью.
Принцип: **плотность и спокойствие уровня Linear/Things, язык — готика DUSK.**
Скоуп: ТОЛЬКО coarse-pointer слой; десктоп байт-в-байт не меняется.

## Диагноз бейслайна (что лечим)

1. Карточка «рыхлая»: 7 вечно видимых иконок-призраков растянуты на всю
   ширину — читаются как декор, а не кнопки; двухсловная задача занимает
   ~200px высоты.
2. Подзадача = карточка с 6 вечными иконками: однословная «первая» ≈ 145px.
   Иерархия инвертирована — подпункт тяжелее родителя.
3. Тулбар = трёхэтажный шкаф (7+4+5 кнопок, лейблы ВИД/ФИЛЬТР/ДАННЫЕ,
   обрубки разделителей).
4. Шапка ≈ 250px до табов (DUSK + typewriter-тэглайн + орнамент).
5. Разнобой выравниваний; фокус-кольцо на первом пункте шита; каскад входа
   ~2.8с; dashed-кнопки «+ГРУППА/ШАБЛОНЫ» выглядят черновыми.

## Ключевой ход: конфигурация уходит в шит, статус остаётся на карте

Ряд действий на карточке — это НЕ ежедневные действия, это конфигурация
(назначить дедлайн/повтор/цвет/приоритет). Ежедневное: чек (гроб), открыть
подпункты/заметку, изменить дедлайн с чипа. Поэтому:

- **Карточка задачи (coarse):** `[гроб 40] Заголовок …… [⋯ 40]` — ряд 1;
  ряд 2 = мета-чипы ТОЛЬКО с информацией (дедлайн-пилюля, повтор,
  подпункты N/M, заметка). Вечный ряд 7 иконок УДАЛЁН; всё в task-⋯ шите
  (уже существует, дополняется: Закрепить, Цвет, Дедлайн, Повтор, Приоритет,
  Заметка-в-окне). Порядок в шите: частое сверху.
- **Подзадача:** одна строка `[хэндл][чек][текст][эмбер][⋯]`, min-height 48px;
  дедлайн-чип и заметка-индикатор инлайн под текстом только если есть.
  6 иконок → sub-⋯ шит (Приоритет, Повтор, Дедлайн, Заметка, Сделать задачей,
  Удалить).
- **Групп-хедер:** одна строка `[хэндл][точка][имя][N/M][⋯][меч]`, 48px.
  Sundial/sort/focus + dup/rename/delete → групп-⋯ шит (уже есть, дополнить).
- **Пин:** действие в шите; статус — существующий pinned-маркер карты.

## Токены (4px-ритм)

- Отступы: 4 / 8 / 12 / 16 / 24. Паддинг карты 12×14. Gap заголовок→чипы 6.
- Тап-таргеты ≥40×40 (глиф 18-20px), ряд-таргеты ≥48px.
- Чипы: высота 26, паддинг 3×8, радиус 8, шрифт 12px, глиф 12-14px.
- Радиусы: карта 12, чип/кнопка 8-10. Тени НЕ добавлять (глубина = бордеры
  и фон, как в текущей готике).
- Интерактив-фидбек: `:active` → scale(0.97) + bg rgba(120,60,220,.16),
  transition 120ms var(--ease-*). Только transform/opacity/background.
- Фокус: кольца только на `:focus-visible`; programmatic focus шита — на
  контейнер (tabindex=-1), не на первый пункт.

## Шапка + тулбар (слайс B)

- Шапка coarse: эмблемы + DUSK в один ряд ~44px, тэглайн и typewriter скрыты,
  орнамент-подчерк тонкий; табы сразу под. Цель ≤96px до конца табов.
- Тулбар: поиск + 2 ряда по-прежнему готических кнопок 42px БЕЗ текстовых
  лейблов и обрубков разделителей: ряд 1 = ВИД (7); ряд 2 = ФИЛЬТР (3) +
  ВЫБОР (1) + разделитель + ⋯-инструменты. Блок ДАННЫЕ (импорт/экспорт/
  merge/очистить) целиком в тулбар-⋯ шит с секциями и подписями; деструктив
  внизу, danger-стиль, двухшаговое подтверждение как было.
- «+ГРУППА / ШАБЛОНЫ»: solid ghost-кнопки (тонкий бордер, фон surface),
  без dashed.

## Motion (слайс C)

- Вход списка: stagger 42мс → 28мс, cap 8 (≤224мс суммарно + dur-standard).
- Тэглайн-typewriter не играет на coarse (скрыт вместе с тэглайном).
- Шит: вход 260мс ease-out снизу, scrim fade 200мс; выход 200мс.
- prefers-reduced-motion уважается везде (уже есть — не сломать).

## Архив / Гримуар / пустые состояния (слайс D)

- Архив-карточка: тот же чип-язык (дата = чип), экшены restore/delete 40px
  справа в ряд заголовка, компакт.
- Гримуар-список уже близок; выровнять паддинги по токенам, сниппеты 2 строки.
- Пустые состояния: глиф + 1 строка + CTA; тулбар в пустом списке схлопнут
  (раскрыт только поиск-строка? — решено: скрывать весь тулбар при 0 задач
  НЕЛЬЗЯ (фильтр может прятать), но пустое-состояние с CTA остаётся).

## Что НЕ трогаем

- Десктоп (fine pointer) — байт-в-байт.
- DnD-механику (Sortable, delay-on-touch), split-режим, reconciliation.
- Логику данных, синк, undo.
